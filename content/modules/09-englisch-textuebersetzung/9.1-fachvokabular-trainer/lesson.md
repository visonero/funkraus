Zur praktischen BZF I Prüfung gehört: einen kurzen englischen Text aus den Luftfahrthandbüchern vorlesen und anschließend mündlich ins Deutsche übersetzen. Dafür brauchst du ein Grundvokabular, das in AIP-Einträgen und NOTAMs immer wiederkehrt. Diese Lektion trainiert genau das.

## Die wichtigsten Begriffe

| Englisch | Deutsch |
|---|---|
| AERODROME | Flugplatz |
| RUNWAY (RWY) | Piste |
| TAXIWAY (TWY) | Rollbahn |
| APRON | Vorfeld |
| THRESHOLD | Landebahnschwelle |
| ELEVATION | Höhe über NN |
| CIRCUIT | Platzrunde |
| OBSTACLE | Hindernis |
| PROMULGATED | veröffentlicht |
| WITHDRAWN | zurückgezogen |
| UNSERVICEABLE (U/S) | außer Betrieb |
| CLOSED (CLSD) | gesperrt |
| AVAILABLE (AVBL) | verfügbar |
| EFFECTIVE | gültig ab |
| PERMANENT | dauerhaft |
| TEMPORARY (TEMPO) | vorübergehend |
| PRIOR PERMISSION REQUIRED (PPR) | vorherige Genehmigung erforderlich |

Viele dieser Wörter kennst du in abgekürzter Form aus echten NOTAMs: RWY, TWY, CLSD, AVBL, U/S und TEMPO sind Standardabkürzungen, die in NOTAM-Texten ständig vorkommen.

## So übst du es

Höre die Audioübung an und sprich die deutsche Bedeutung laut mit, bevor du die Antwort hörst. In den nächsten beiden Lektionen wendest du dieses Vokabular direkt auf zwei vollständige Übersetzungstexte an.
