Die Standardredewendungen aus Modul 2 kennst du auf Deutsch schon: VERSTANDEN, WILCO, STANDBY und so weiter. Jetzt lernst du dieselben Bedeutungen mit ihren englischen Wörtern — und ein paar zusätzliche, die im deutschen Funk seltener vorkommen, im internationalen Verkehr aber Standard sind.

## Wörter, die du schon kennst

| Englisch | Deutsch | Bedeutung |
|---|---|---|
| AFFIRM | POSITIV | Ja |
| NEGATIVE | NEGATIV | Nein, Erlaubnis nicht erteilt, oder nicht richtig |
| ROGER | VERSTANDEN | Ich habe Ihre letzte Meldung vollständig erhalten |
| WILCO | WILCO | Verstanden, ich werde entsprechend handeln (von „will comply") |
| STANDBY | STANDBY | Warten Sie, ich werde Sie rufen |
| MONITOR | MONITOR | Hören Sie (Frequenz) ab |
| CONTACT | RUFEN SIE | Stellen Sie Funkverbindung her mit … |
| REPORT | MELDEN SIE | Geben Sie mir die folgende Information |
| REQUEST | ERBITTE | Ich möchte wissen, oder: ich beantrage |
| OVER | KOMMEN | Meine Übermittlung ist beendet, ich erwarte Ihre Antwort |
| OUT | ENDE | Übermittlung beendet, ich erwarte keine Antwort |
| SPEAK SLOWER | SPRECHEN SIE LANGSAMER | Vermindern Sie Ihre Sprechgeschwindigkeit |
| SAY AGAIN | WIEDERHOLEN SIE | Wiederholen Sie alles oder einen Teil Ihrer Meldung |
| I SAY AGAIN | ICH WIEDERHOLE | Ich wiederhole zur Klarstellung oder Betonung |
| READ BACK | WIEDERHOLEN SIE WÖRTLICH | Wiederholen Sie die Meldung wörtlich (Read-back) |

## Eine Falle: zwei englische Wörter, eine deutsche Übersetzung

Im Deutschen heißt beides „BESTÄTIGEN SIE". Im Englischen sind es zwei verschiedene Wörter mit unterschiedlicher Bedeutung:

| Englisch | Bedeutung |
|---|---|
| ACKNOWLEDGE | Teilen Sie mit, dass die Meldung empfangen und verstanden wurde |
| CONFIRM | Ich erbitte Bestätigung einer Freigabe, Anweisung, Handlung oder Information |

## Neue Redewendungen für den internationalen Funk

Diese Wörter kommen im deutschen Funk seltener vor, sind für BZF I aber Pflichtstoff:

| Englisch | Bedeutung |
|---|---|
| APPROVED | Erlaubnis für das vorgeschlagene Verfahren erteilt |
| BREAK | Ich zeige die Trennung zwischen Teilen der Meldung an |
| BREAK BREAK | Trennung zwischen Meldungen an verschiedene Luftfahrzeuge in hochbelasteter Verkehrssituation |
| CANCEL | Die vorher übermittelte Freigabe ist aufgehoben |
| CHECK | Prüfen Sie ein System oder Verfahren |
| CLEARED | Genehmigung, unter festgelegten Bedingungen zu verfahren |
| CORRECT | Wahr oder richtig |
| CORRECTION | Bei der Übermittlung ist ein Fehler unterlaufen, es muss richtig heißen … |
| DISREGARD | Ignorieren Sie (selbsterklärend) |
| HOW DO YOU READ | Wie ist die Verständlichkeit meiner Sendung |
| MAINTAIN | Behalten Sie … bei, oder: bleiben Sie … (fahren Sie gemäß den festgelegten Bedingungen fort) |
| RECLEARED | Ihre neue Freigabe ersetzt die vorherige ganz oder teilweise |
| UNABLE | Ich kann Ihrer Anfrage, Anweisung oder Freigabe nicht folgen |
| WORDS TWICE | Bitte senden Sie jedes Wort doppelt (oder: ich sende jedes Wort doppelt), weil die Verständigung schwierig ist |

## Der Sonderfall TAKE-OFF

Das Wort **TAKE-OFF** darfst du im Sprechfunk nur verwenden, wenn ein Luftfahrzeug tatsächlich zum Start freigegeben wird oder eine Startfreigabe aufgehoben wird — genau wie beim deutschen „START FREI". In jedem anderen Zusammenhang sprichst du stattdessen von „DEPARTURE".
